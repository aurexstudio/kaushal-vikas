Features
Two project cards side by side, equal in size and layout
Light and dark mode
Optional background music (starts only when you press Play)
Works on phones, tablets and computers
Single file: plain HTML, CSS and JavaScript, no installation needed
Run it locally
Download or clone this repository.
Open index.html in any web browser.
Publish with GitHub Pages
Go to Settings → Pages.
Under "Build and deployment", choose Deploy from a branch.
Select the main branch and the / (root) folder, then press Save.
Wait a minute or two. Your live link appears at the top of the Pages screen.
